# เว็บไซต์สะสมผลงานวิชาการและรายวิชาการเรียน - ครูอ๋อน (Academic E-Portfolio)

เว็บไซต์สะสมผลงานและรวบรวมผลงานประจำรายวิชา นวัตกรรมการสอน และผลงานนักเรียน ออกแบบพิเศษตามความต้องการของ **ครูอ๋อน**:
- **โทนสี:** ขาว ผสานสีครีมและน้ำตาลอ่อน (Warm Cream & Soft Brown) สไตล์ Minimal Academic ภูมิฐาน อบอุ่น สบายตา
- **โหมดสีดำ (Dark Mode):** มีปุ่มสลับโหมดมืดลึกอบอุ่น (Espresso Dark Mode) พร้อมบันทึกสถานะอัตโนมัติ
- **หน้าโชว์อาจารย์เฉพาะวิชาการ:** นำเสนอประวัติการสอน ปรัชญาการศึกษา วุฒิการศึกษา รายวิชาที่รับผิดชอบ และเกียรติประวัติทางวิชาการ
- **คลังเก็บข้อมูลผลงานของรายวิชา:** จัดหมวดหมู่แยกตามรหัสวิชา, ผลงานนักเรียน, สื่อนวัตกรรมการสอน, แผนการสอน/ใบงาน และรางวัลผลสัมฤทธิ์
- **แก้ไขข้อมูลได้ทั้งหมด (Live Edit System):** มีระบบจัดการข้อมูลในตัว เพิ่ม/แก้ไข/ลบ ได้ทั้งผ่านหน้าเว็บและผ่านไฟล์ข้อมูล

```

│   └── style.css       # โทนสีขาว-น้ำตาลอ่อน, โหมดสีดำ, ฟอนต์ Prompt & Sarabun, การจัดพิมพ์

│   └── app.js          # ระบบจัดการเว็บ การสลับโหมดสี การกรองผลงาน และระบบแก้ไข
├── assets\

│   └── docs\           # โฟลเดอร์สำหรับเก็บไฟล์ PDF / แผนการสอน
```

## 💻 วิธีการเปิดใช้งาน

1. ไปที่โฟลเดอร์ `D:\งานครูอ๋อน\website\`
2. **ดับเบิลคลิกที่ไฟล์ `index.html`** เพื่อเปิดดูเว็บไซต์ผ่านเบราว์เซอร์ (เช่น Google Chrome, Microsoft Edge, Safari)
3. ใช้งานได้ทันที **โดยไม่ต้องติดตั้งโปรแกรมเสริมหรือเปิดเซิร์ฟเวอร์ใดๆ**

## ✏️ วิธีการแก้ไขข้อมูล (2 วิธี)

### วิธีที่ 1: แก้ไขผ่านหน้าเว็บไซต์โดยตรง (แนะนำ ง่ายและสะดวกที่สุด)
1. เปิดหน้าเว็บ `index.html`
2. คลิกปุ่ม **"โหมดแก้ไขข้อมูล"** ที่เมนูด้านบนขวา
3. จะปรากฏปุ่มควบคุมสำหรับจัดการข้อมูล:
   - **แก้ไขประวัติอาจารย์:** คลิกปุ่ม *"แก้ไขข้อมูลประวัติอาจารย์"* ในส่วนบนสุด
   - **เพิ่ม/แก้ไขรายวิชา:** คลิกปุ่ม *"เพิ่มรายวิชาใหม่"* หรือไอคอนดินสอบนการ์ดรายวิชา
   - **เพิ่ม/แก้ไขผลงาน:** คลิกปุ่ม *"เพิ่มผลงานใหม่ในวิชา"* หรือไอคอนดินสอบนการ์ดผลงาน (สามารถเลือกรูปจากเครื่องคอมพิวเตอร์ได้ทันที)
   - **ลบข้อมูล:** คลิกไอคอนถังขยะสีแดงเพื่อลบรายการที่ไม่ต้องการ
4. ระบบจะบันทึกการเปลี่ยนแปลงลงในเบราว์เซอร์อัตโนมัติ
5. **การสำรองข้อมูล:** สามารถคลิกปุ่ม **"สำรองไฟล์ JSON"** เพื่อดาวน์โหลดไฟล์เก็บไว้ และสามารถนำเข้าด้วยปุ่ม **"นำเข้า JSON"** ได้ทุกเมื่อ

### วิธีที่ 2: แก้ไขผ่านโค้ดในไฟล์ `js/data.js`
เปิดไฟล์ `js/data.js` ด้วยโปรแกรมแก้ไขข้อความ (เช่น Notepad, VS Code) แล้วแก้ไขข้อความในตัวแปร `defaultPortfolioData` ตามที่ต้องการ (มีคำอธิบายภาษาไทยกำกับทุกส่วน)

## 🖨️ การพิมพ์และส่งออกเป็น PDF (สำหรับประเมิน ว.PA)
- คลิกที่ปุ่ม **"พิมพ์ / PDF"** ที่มุมบนขวา หรือกดคีย์ลัด `Ctrl + P`
- ระบบได้รับการปรับแต่ง Layout หน้ากระดาษสำหรับการพิมพ์ให้อ่านง่าย ชัดเจน และตัดปุ่มควบคุมที่ไม่จำเป็นออกอัตโนมัติ เพื่อนำไปจัดทำเล่มรายงานหรือแฟ้มประเมิน
