# เว็บไซต์สะสมผลงาน (Student Portfolio) - นาย พุศิพงศ์ ราชรักษ์

ระบบเว็บไซต์สะสมผลงานนักศึกษาและคลังผลงานโครงงานซอฟต์แวร์ รายวิชา **31901-2009 การพัฒนาซอฟต์แวร์สำหรับอุปกรณ์เคลื่อนที่**
- **เจ้าของเว็บไซต์ (Student):** **นาย พุศิพงศ์ ราชรักษ์** ระดับชั้น ปวส.2 สทส2 เลขที่ 12 กลุ่ม 1 สาขาเทคโนโลยีสารสนเทศ ประเภทวิชา อุตสาหกรรมดิจิตอลและสารสนเทศ
- **ครูผู้สอน / ที่ปรึกษา (Instructor):** **ครูอ๋อน (อาจารย์อ๋อน)**
- **Frontend:** **Angular 19** (HTML5, CSS3, TypeScript) ออกแบบในโทนสี **ขาว ครีม และน้ำตาลอ่อน (Warm Cream & Soft Brown)** พร้อมสลับ **โหมดสีดำ (Dark Mode)**
- **Backend:** **Golang (Go)** REST API ประสิทธิภาพสูง พร้อม CRUD ครบทุกฟังก์ชัน
- **Database:** เตรียมพร้อมเชื่อมต่อกับ **TiDB** (MySQL-Compatible Distributed SQL Database พอร์ต 4000) พร้อมระบบ Auto-Migrate และ Smart Fallback (SQLite pure-Go)

## 🚀 วิธีการรันระบบ (Quick Start)

### วิธีที่ 1: รันด้วย 1-Click (แนะนำ)
ดับเบิลคลิกไฟล์ **`start_all.bat`**  
ระบบจะทำการเปิดหน้าต่าง Backend (Go) และ Frontend (Angular) พร้อมเปิดเบราว์เซอร์ไปยัง `http://localhost:4200` อัตโนมัติ

### วิธีที่ 2: รันแยกทีละส่วนผ่าน Terminal

1. **เปิดรัน Backend (Go):**
   ```powershell
   cd D:\งานครูอ๋อน\website\backend
   go run main.go
   ```
   *เซิร์ฟเวอร์จะเปิดที่ `http://localhost:8080` (API Base: `http://localhost:8080/api`)*

2. **เปิดรัน Frontend (Angular):**
   ```powershell
   cd D:\งานครูอ๋อน\website\frontend
   npx ng serve --open
   ```
   *หน้าเว็บจะเปิดที่ `http://localhost:4200`*

## 🗄️ การเชื่อมต่อกับฐานข้อมูล TiDB

ระบบหลังบ้าน Go ได้จัดเตรียมการเชื่อมต่อกับ **TiDB** ไว้อย่างสมบูรณ์ (โดยใช้พอร์ตมาตรฐานของ TiDB คือ `4000`):

### 1. การตั้งค่า `.env` สำหรับ TiDB Cloud (เชื่อมต่อแล้วพร้อมใช้งาน)
ไฟล์ `backend/.env` ได้รับการกำหนดค่าเข้ากับคลัสเตอร์ **TiDB Cloud Serverless** โดยตรง:

```env
# TiDB Cloud Serverless (AWS ap-southeast-1)
TIDB_HOST=gateway01.ap-southeast-1.prod.aws.tidbcloud.com
TIDB_PORT=4000
TIDB_USER=2FDBJnxUfTZqpcH.root
TIDB_PASSWORD=g292imtwbDzVbbHc
TIDB_DATABASE=test
TIDB_TLS=true
PORT=8080
```

### 2. ระบบภาพผลงาน (ภาพหน้างาน & ภาพข้างใน)
- 🖼️ **ภาพหน้างาน (ภาพปกหลัก):** แสดงเป็นหน้าปกการ์ดผลงานและหัวข้อหลัก
- 📸 **ภาพข้างใน (ภาพประกอบ / Gallery):** สามารถเลือกอัปโหลดไฟล์รูปภาพจากเครื่องหลายรูปพร้อมกัน หรือใส่ URL ได้ไม่จำกัด ระบบจะจัดเก็บและแสดงผลเป็นแท็บแกลเลอรีให้คลิกดูรูปใหญ่ได้อย่างคมชัด

### 3. ระบบ Smart Auto-Fallback
หากเกิดปัญหาอินเทอร์เน็ตในการเชื่อมต่อ Cloud TiDB ระบบหลังบ้าน Go จะตรวจพบและสลับไปใช้ **SQLite Development Database (`kruaon_dev.db`) อัตโนมัติทันที** เพื่อให้หน้าเว็บทำงานได้ต่อเนื่องไม่สะดุด

## 🎨 ฟีเจอร์เด่นบนหน้าเว็บ Angular
 
1. **หน้าโชว์ประวัตินักศึกษาและรายวิชาหลัก:** แสดงข้อมูลส่วนตัวของ นาย พุศิพงศ์ ราชรักษ์ ปวส.2 สทส2 เลขที่ 12 กลุ่ม 1 สาขาเทคโนโลยีสารสนเทศ รายวิชา 31901-2009 การพัฒนาซอฟต์แวร์สำหรับอุปกรณ์เคลื่อนที่ และระบุครูผู้สอน/ที่ปรึกษาคือ ครูอ๋อน
2. **คลังผลงานประจำรายวิชา:** สามารถคลิกสลับแท็บรหัสวิชา, กรองประเภทผลงานนักศึกษา/สื่อนวัตกรรม/แผนการสอน/รางวัล, พร้อมช่องค้นหาแบบเรียลไทม์
3. **โหมดแก้ไขข้อมูล (Live Edit Mode):** คลิกปุ่ม *"โหมดแก้ไข"* ที่เมนูด้านบน จะมีปุ่มเพิ่ม/แก้ไข/ลบรายวิชา และผลงานได้ทันที พร้อมอัปโหลดภาพจากเครื่องคอมพิวเตอร์
4. **โหมดสีขาว-น้ำตาลอ่อน และ โหมดสีดำ:** สลับโทนสีได้ทันทีด้วยปุ่มดวงจันทร์/ดวงอาทิตย์
5. **พิมพ์และส่งออกเป็น PDF:** รองรับการจัดหน้ากระดาษแบบ A4 สำหรับใช้แนบรายงานแฟ้มประเมินผลการเรียน
6. **เชื่อมต่อ Backend Golang & TiDB:** มีปุ่มตรวจเช็คสถานะฐานข้อมูล TiDB / Backend แบบ Real-time บนแถบนำทาง (Navbar)
